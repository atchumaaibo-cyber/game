# ユウマクエスト

王様に呼ばれた犬の勇者ユウマが使命を受け、城を出た瞬間にオヤツを見つけて食べ、使命を忘れてエンディングを迎える、約2分のブラウザ3Dゲーム。

## あそぶ

**一番かんたん**: リポジトリのルートにある `遊ぶ_ユウマクエスト.bat`（Windows）か `遊ぶ_ユウマクエスト.command`（Mac）をダブルクリック。Python が必要。

手動なら、リポジトリのルートで静的サーバーを立てて開く（`file://` では読み込めない）。

```
python3 -m http.server 8000
# → http://localhost:8000/games/yuma-quest/index.html
```

GitHub Pages を `main` のルートで有効にすれば `https://<user>.github.io/game/games/yuma-quest/` で遊べる。

- 移動: WASD / 矢印キー（スマホは画面左下のスティック）
- カメラ: Q E / 横ドラッグ
- メッセージ送り: スペース / クリック / タップ
- `?autostart` を付けるとタイトルを飛ばして始まる（動作確認用）

## 中身

- `index.html` / `js/main.js` … ゲーム本体（Three.js r170。`lib/` に同梱、CDN 不要）
- `js/music.js` … BGM と効果音。音源ファイルは使わず Web Audio で鳴らす自作シンセ（王様の行進曲 / オヤツのジングル / エンディングのオルゴール）
- 素材は `../../assets/`（ユウマ、あっち、静岡の箱庭）をそのまま読む
- 王様はあっちのモデルに王冠とマントを足した仮の姿。オヤツは仮の「ほねガム」
- 城の堀の段差をつなぐため、木のスロープをコードで足している
