# パンデミック 2卓そろえ山札

ボードゲーム「パンデミック」を2つの卓で同時に遊ぶとき、両方の卓でプレイヤーカードと感染カードが同じ順に出るようにする、スマホ用の山札進行の道具。実物のカードは手元のものを使い、この道具は順番と表示だけを受け持つ。

- 開き方：`https://atchumaaibo-cyber.github.io/game/games/pandemic/`（家のLANでは PC01 の `http://192.168.1.101:8710/game/pandemic` でも同じもの）
- 2卓のそろえ方：同じ合言葉・人数・エピデミック枚数で始める。2台は通信しない。画面の「共有」から、もう1卓用のリンク（最初から）と、別のスマホへ続きを渡すリンク（進行ごと）を送れる。
- 中身：`index.html` 1枚（CSSとJSを中に入れた形）。元は PC01 の `\\PC01\me\50_PROJECT\20ゲーム制作\パンデミック山札\index.html`。
