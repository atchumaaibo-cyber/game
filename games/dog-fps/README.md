# 犬FPS オヤツでとめろ！

箱庭（安倍川公園）の中で、使うキャラを選んで遊ぶブラウザ 3D ゲーム（Three.js）。選ばれなかった犬たちとあっちが、ゾンビみたいにぐらぐら迫ってくる。**好物のオヤツ**を投げると夢中になって動かなくなる。3つのウェーブ（敵 4→6→8 人）を全部とめたらクリア、3回つかまったら負け。

## 遊び方

1. リポジトリのいちばん上にある **`遊ぶ_犬FPS.bat`**（Windows）か **`遊ぶ_犬FPS.command`**（Mac）をダブルクリックする（Python が必要）
2. 黒い画面が開いて、ブラウザに犬FPSが出る。遊び終わったら黒い画面を閉じる
3. 動かないときは、リポジトリのルートで `python3 -m http.server 8001` を実行して http://localhost:8001/games/dog-fps/ を開く（`index.html` を直接開くと動かない）

- 操作: `WASD` 歩く / `Shift` 走る / `Space` ジャンプ / マウスで見回す / クリックでオヤツを投げる / `1`〜`5` かホイールでオヤツを変える / `Esc` 一時停止
- 好物は頭の上の吹き出しに出る（ユウマ=みかん、プードル=せんべい、ポメ=まんじゅう、ぽんねこ=しらす、あっち=ハンバーグ）。ちがうオヤツだと、においをかいで 3 秒止まるだけ
- 地面に落ちたオヤツも、近くを通った子は食べる
- **オヤツの数には限りがある**（はじめ10個、最大20個）。地面の金色の光の柱が **オヤツ箱**（近くを通ると +8 個）。ウェーブが変わると +6 個、ハートも1つ回復
- 点数: 1人とめるごとに 100 点、近く（6m 以内）でとめると +50、4秒以内に続けてとめるとコンボで +50 ずつ増える。ウェーブクリアで +200。ベスト点はブラウザに残る
- 左下に、選んだキャラの顔・名前・ハートが出る。右下の手が持っているのが、いま選んでいるオヤツ

## 中身

- `main.js` … ゲーム全部（読み込み・キャラ選び・操作・敵の動き・オヤツ・ウェーブ・点数）。好物や見せ寸は先頭の `CHARS` / `TREATS`、ウェーブの人数やオヤツの数は `WAVES` / `AMMO_*` で変える
- `lite/` … ブラウザで軽く動かすための軽量版（キャラは約 3 万三角形・1024px 画像に減らし、箱庭は圧縮しただけ。計 約 7MB）。元は `assets/`
- `tools/make-lite.mjs` … `lite/` を作り直す: `cd games/dog-fps/tools && npm install && npm run lite`
- `vendor/three/` … Three.js 0.186（オフラインで動かすため同梱）

## いまの限界（最小版）

- BGM・本物の効果音は無い（効果音は WebAudio の簡単な音）。オヤツは丸や四角で作った仮の形
- 「食べる」は座って頭を揺らすだけ（専用の動きは未作成）。ゾンビの動きは骨を回して腕を前に出し、体を傾けて作っている
- 当たり判定は「地面の高さ」と木・小屋などの箱だけ。遊べる範囲は安倍川公園の一部
- 毛（ファー）は入っていない（docs/assets.md 参照）
