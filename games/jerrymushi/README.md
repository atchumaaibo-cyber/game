# ジェリームシの大冒険

イモムシになったジェリーが前に進むと光る石板があって、ぶつかると「ジェリー もう羽化したほうがいいよ（ティロリロリン）」。さなぎになって、ジェリーに戻る。約1分、スマホ向けのブラウザ3Dゲーム。

## あそぶ

GitHub Pages: `https://atchumaaibo-cyber.github.io/game/games/jerrymushi/`

手元で動かすなら、リポジトリのルートで `python3 -m http.server 8000` → `http://localhost:8000/games/jerrymushi/`

- 操作: 画面を指でさわって**よこに動かす**とイモムシが曲がる（パソコンは ← → / A D）。前には自動で這う
- `?autostart` でタイトルを飛ばす / `?near` で石板が近くに出る（動作確認用）

## 中身

- `models/jerry.glb` … ジェリーイモムシ v1（`ジェリー/イモムシ/ジェリーイモムシ_v1.glb` のコピー）。GLB に動きは入っていないので、`main.js` の `animateCat` が節（head, seg1〜seg6）の回転を波で動かす（元の README の見本と同じ：後ろから前へ進む波、隣と0.9rad ずれ。振れは見本の0.11より大きめ）
- `models/jerry-end.glb` … ジェリー（Jerry_baked_v99.glb を軽量化：頂点を約1/9、テクスチャ1024px）。最後に出てきて手をふる（wave_A）
- 光る石板・さなぎ・背景は、モデルがないのでコードで作った仮の姿
- 蛹→ジェリーに戻る「動画」は素材がなかったので、3D演出（糸のきらめき・ぶるぶる・発光・フラッシュ・紙吹雪・ティロリロリン）で代用
- 音は音源ファイルなし。Web Audio の自作シンセ
- Three.js r170 を `lib/` に同梱（CDN 不要）

## 蛹→ジェリーの動画を差し替える

動画生成AIなどで作った動画を `games/jerrymushi/media/hanka.mp4` という名前で置くと、3D演出のかわりにその動画が流れ（終わるとジェリーが登場）、置かなければ3D演出になる。縦長（スマホ向け）・数秒〜10秒ほどがおすすめ。
