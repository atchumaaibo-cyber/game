### 1-2. 骨（リグ）と動き

- 5体とも**共通の骨 17 本**（`hips, spine, chest, neck, head, upper_arm.L/R, forearm.L/R, hand.L/R, thigh.L/R, shin.L/R, foot.L/R`）。名前・親子が同じなので、**あるキャラの動きを別のキャラに名前で流せる**（Three.js で骨の名前が一致するトラックはそのまま効く）
  - 左右: `.L` がキャラの左（Blender の +X）
  - 共通の動きは共通の17本にだけ鍵がある。耳・尻尾（追加の骨）は動きに入っていない
  - **例外: あっちは腕が A ポーズ（斜め下 44°）が元の姿勢**で、ほかは T ポーズ。回転をそのまま流すと、あっちの腕の角度がずれる。あっちに他キャラの動きを使うときは「骨の向き」を合わせて載せる（PC 側に道具あり）。**あっちは肩より上に腕を上げない**（上げると服が崩れる。骨に `arm_max_deg=0`）
- 動きの名前（共通）:
  - `idle` 待機 / `walk` その場歩き / `walk_root` 前へ進む歩き（腰が前へ動く） / `wave` 手を振る（挨拶）
  - `hiphop` ユウマだけ。Mixamo の Hip Hop Dancing を載せ替えたもの
  - `walk_original` あっちだけ（前かがみの昔の歩き）
  - **走る動きはまだ無い**（下の「ゲームに足りないもの」）
- 向き: Blender で**正面は -Y**。glTF では **+Z が正面、+Y が上**（Three.js の標準のまま、`lookAt` で向けられる）
- 足の裏: 元の姿勢で z≈-0.5（ユウマ）/ -0.95（ほか）。モデルの原点は腰のあたりなので、床に置くときは足の裏の分だけ上げる（`meta.json` の `foot_z`）

### 1-3. 見た目の注意

- **毛**: ユウマ・プードル・ポメは Blender では本物の毛（パーティクル）で作ってあるが、GLB には入らない（つるっとした見た目になる）。Unity 版は「殻の毛」（何枚も重ねた薄い殻）で出している。Three.js でも同じ方法（シェル・ファー）で後から足せる
- **表情**: プードル・あっち・ぽんねこは顔の絵を差し替えて表情を出す（`textures/` の `*_face_e0_m0` / `head_e1_m2` / `pon_head_eyeClosed_mouthA` など。e＝目、m＝口の番号）
- ユウマの顔は形状キー（morph target）で口とまぶたが動く
